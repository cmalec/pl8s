# Developer Connection

Source: https://developer.repebble.com/guides/tools-and-resources/developer-connection/

In order to install apps from the local SDK using the `pebble` tool, the Pebble
Android or iOS app must be set up to allow a connection from the computer to the
watch. This enables viewing logs and installing apps directly from the
development environment, speeding up development.

Follow the steps illustrated below to get started.

## Android Instructions

In the Pebble mobile app:

- Open the overflow menu by tapping the three dot icon at the top right and tap
*Settings*.

![Pebble Android app settings menu](https://developer.repebble.com/assets/images/guides/publishing-tools/enable-dev-android-1.png)

- Enable the *Developer Mode* option.

![Pebble Android app with Developer Mode enabled](https://developer.repebble.com/assets/images/guides/publishing-tools/enable-dev-android-2.png)

- Tap *Developer Connection* and enable the developer connection using the
toggle at the top right.

![Pebble Android app Developer Connection screen](https://developer.repebble.com/assets/images/guides/publishing-tools/enable-dev-android-4.png)

- Make note of the 'Server IP' and use it with the `--phone` argument.

## iOS Instructions

In the Pebble mobile app:

- Open the left-hand menu and tap the *Settings* item.

![Pebble iOS app settings menu](https://developer.repebble.com/assets/images/guides/publishing-tools/enable-dev-ios-1.png)

- Enable the Developer Mode using the toggle.

![Pebble iOS app with Developer Mode enabled](https://developer.repebble.com/assets/images/guides/publishing-tools/enable-dev-ios-2.png)

- Return to the menu, then tap the *Developer* item. Enable the Developer
Connection using the toggle at the top-right.

![Pebble iOS app Developer item screen](https://developer.repebble.com/assets/images/guides/publishing-tools/enable-dev-ios-3.png)

- Make note of the 'Server IP' and use it with the `--phone` argument.
